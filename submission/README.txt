Дополнение к Git-репозиторию: reports/ содержит реальные метрики и raw-ответы; eval-data.zip содержит набор оценки и полный train-index. Веса и тензоры обучения отсутствуют. Разархивируйте eval-data.zip в корень проекта, затем uv run dvc add data/eval для локального восстановления кэша. Итоговые проверки и видео выполняет студент.
